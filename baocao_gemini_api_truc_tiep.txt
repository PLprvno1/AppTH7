BÁO CÁO TÍCH HỢP GEMINI API TRỰC TIẾP
======================================

Ngày: 29/10/2026
Project: F:\AppTH7

1. ĐÃ TRIỂN KHAI
----------------
- Thêm GeminiApiService dùng HTTPS REST generateContent, header
  x-goog-api-key, HttpURLConnection và org.json có sẵn trong Android. Không
  thêm thư viện hoặc backend.
- Model: gemini-3.8-flash. Endpoint:
  https://generativelanguage.googleapis.com/v1beta/models/gemini-3.8-flash:generateContent
- Nút “Phân tích bằng Gemini AI” nằm trong tab Coach. Chỉ gửi yêu cầu khi người
  dùng nhấn nút; lời khuyên Java hiện có vẫn hoạt động độc lập.
- Prompt gồm mức pin, trạng thái/nguồn sạc Android, điện áp/dòng điện khi có,
  chế độ tiết kiệm pin, tối đa sáu mẫu pin thực gần nhất và lời khuyên
  BatteryCoachEngine. Không gửi lịch sử ứng dụng hoặc dữ liệu định danh.
- Kết quả được trình bày riêng; trạng thái loading, lỗi mạng/timeout, HTTP 400,
  401, 403, 404, 429, 5xx, safety và phản hồi sai định dạng được xử lý. Có
  timeout, giới hạn kích thước phản hồi và khoảng chờ cục bộ 20 giây giữa các
  yêu cầu. Không ghi prompt, phản hồi hay API key vào log.
- Nếu Fragment bị hủy, tác vụ bị hủy và kết quả cũ không cập nhật giao diện.
- API key được đọc từ local.properties (GEMINI_API_KEY) hoặc biến môi trường
  cùng tên để sinh BuildConfig. Khi tích hợp ban đầu, thuộc tính được tạo rỗng;
  sau đó người dùng đã cấu hình khóa cục bộ.

2. AN TOÀN VÀ GIỚI HẠN
----------------------
- Khóa đã dán trong hội thoại không được sử dụng. Hãy thu hồi khóa đó và tạo
  khóa mới. Đặt khóa mới vào GEMINI_API_KEY trong local.properties trên máy
  phát triển, rồi build lại. Không đưa khóa vào source, báo cáo hay Git.
- Dù đọc từ local.properties, khóa được biên dịch vào APK BuildConfig và có thể
  bị trích xuất từ APK. Đây chỉ phù hợp cho bản thử nghiệm cá nhân; bản phát
  hành cho người dùng cần proxy/backend giữ khóa.
- Gemini chỉ bổ sung giải thích. Prompt cấm suy đoán nhiệt độ, phần trăm sức
  khỏe, dung lượng pin, mức hao pin theo ứng dụng hoặc thời lượng còn lại; AI
  không điều khiển cài đặt Android.
- Dữ liệu gửi đến Gemini khi bấm nút rời khỏi thiết bị để xử lý API. Ứng dụng
  không lưu kết quả/prompt vào SQLite và không tự gửi nền.
- Đã thêm quyền INTERNET; không thêm quyền runtime hoặc quyền pin khác.

3. FILE ĐÃ SỬA
--------------
- app/build.gradle.kts — nạp khóa cục bộ/biến môi trường vào BuildConfig.
- app/src/main/AndroidManifest.xml — quyền INTERNET.
- app/src/main/java/com/example/th7/data/GeminiApiService.java — REST client,
  parse văn bản và phân loại lỗi.
- app/src/main/java/com/example/th7/ui/BatteryCoachFragment.java — hành động
  thủ công, lấy dữ liệu pin/advice, gửi prompt và cập nhật kết quả an toàn.
- app/src/main/res/layout/fragment_battery_coach.xml — thẻ Gemini.
- app/src/main/res/values/strings.xml — nhãn, hướng dẫn và thông báo lỗi.
- local.properties — thêm thuộc tính GEMINI_API_KEY rỗng để cấu hình tại máy.
- baocao_gemini_api_truc_tiep.txt — báo cáo này.

-----------

- Chưa chạy instrumentation test.

5. NGUỒN API
------------
- REST reference: https://ai.google.dev/api
- Model: https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash
- API key security: https://ai.google.dev/gemini-api/docs/generate-content/api-key

Các nguồn trên được dùng để chọn endpoint/model và header. Kết quả gọi API thật
chưa được kiểm chứng; xem cập nhật sửa lỗi ở Mục 6.

6. CẬP NHẬT SAU SỬA LỖI PHẢN HỒI GEMINI
----------------------------------------
- Đã sửa request config `thinkingLevel` thành enum REST `LOW` viết hoa; trước
  đó gửi `low`, có thể khiến API trả lỗi yêu cầu không hợp lệ. Gemini REST mô tả
  trường này là enum `ThinkingLevel`.
- Tăng read timeout lên 60 giây và giới hạn output lên 2048 token để giảm khả
  năng hết thời gian khi model tạo phản hồi.
- Trạng thái key trong local.properties và BuildConfig được kiểm tra chỉ dưới
  dạng có/không; không in khóa và không gửi request thử.
- Đã bỏ thẻ Trợ lý pin khỏi Dashboard và gỡ phần tính lời khuyên không còn được
  hiển thị trên màn hình này.
- Build/test sau cập nhật: BUILD SUCCESSFUL, 37 unit test, 0 failure/error.
- Chưa thể xác nhận phản hồi trực tiếp từ Gemini hoặc UI trên AVD: adb vẫn không
  khả dụng trong môi trường này. Cần chạy app trên thiết bị để xác nhận API key,
  quyền/quota của dự án Google và kết quả phản hồi thật.
